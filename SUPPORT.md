# Support

Use GitHub Discussions for usage questions and ideas. Use Issues for reproducible
bugs and accepted feature work.

Before reporting a connectivity problem, include the host operating system,
selected QR address, guest browser, whether both devices are on the same subnet,
and whether the router enables wireless client isolation. Never post a live QR
capability or private filename unless it is safe to disclose.

Security reports belong in GitHub private vulnerability reporting:
`https://github.com/SidUParis/wiferry/security/advisories/new`.
